## 阅读闭环

1. **首页** — 文章卡片 + home_top + bbTimeList
2. **文章页** — 封面、元信息、TOC、版权、分页、相关文章、打赏、工具条、AI 摘要
3. **归档 / 分类 / 标签 / 404**
4. **侧栏** — 核心六件套 + 公告 + 微信 + 自定义卡片

## 客户端

- 深色模式切换
- 本地搜索（`index.json`）
- 代码复制按钮
- TOC 滚动高亮
- pjax 局部刷新
- 右键菜单 / 控制台 / 快捷键 / 预加载

## 内容与页面

- Content Tags → shortcodes（见 [短代码演示](/posts/shortcodes-demo/)）
- 特殊页：关于、友链、即刻、相册、好物、音乐、朋友圈、房间、追番、小空调
- 转换器：`tools/hexo-to-hugo.js`
- PWA：`manifest.json` + `sw.js`
